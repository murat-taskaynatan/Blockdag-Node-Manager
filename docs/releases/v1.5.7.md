# Release Notes — v1.5.7 (2025-11-15)

## Liveness & Stability
- The manager now treats the `Shutdown complete` log line and the `The dag data was damaged (Can't find tip:...)` error as liveness failsafe triggers, ensuring stalled containers expose a precise reason in the UI before any automated recovery occurs.
- Version badge, `APP_VERSION`, and health reporting all flow through the updated string so dashboards immediately reflect the new release without additional overrides.

## Installer & Bootstrap
- `install_node_manager.sh`, `install_nm_from_github.sh`, and the remote bootstrap link in the README now default to `v1.5.7`, so fresh deployments and `/opt/blockdag-node-manager` installs pull the same tag the UI advertises.
- Remote installer output includes the chosen tag, matching the release notes expectation for reproducible deployments.

## Upgrade Guidance
- Tag `v1.5.7`, push `main`, and run `./scripts/sync_opt_install.sh` after pushing so `/opt/blockdag-node-manager` pulls the release without manual cleanup.
- Remote hosts can still pass `REPO_REF` or `REPO_BRANCH` to the installer; pointing at `v1.5.7` keeps automation aligned while the main branch continues evolving.
