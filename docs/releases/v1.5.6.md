# Release Notes — v1.5.6 (2025-11-17)

## Highlights
- Start/stop controls now behave instantly: buttons stay disabled with a spinner, never flicker between states, and health chips update the moment Docker reports the change.
- Snapshot/restore buttons show live, determinate progress rings (with matching restore spinners) so it’s obvious when a job is running and how far it has advanced.
- Snapshot completion triggers immediate node/metrics refreshes, eliminating the lag between a job finishing and card health chips catching up.
- Installers and UI defaults point at `v1.5.6`, keeping fresh deployments and remote bootstrap scripts in lockstep with the release.

## Fleet Controls & UI
- Added per-node “pending” state tracking for container toggles. Start/stop/restart buttons stay disabled, show the new spinner, and retain the expected icon until `/api/control` confirms success.
- The UI applies optimistic status patches and, if needed, forces metrics polling so health chips and uptime data flip as soon as Docker reflects the requested state.
- Snapshot/restore buttons reuse the discovery-style spinner until a job reports progress, then render a translucent green donut that fills based on `progress.pct`. Restore buttons share the same treatment for visual consistency.

## Snapshot & Recovery
- Snapshot and restore completion now calls `loadNodes()`/`refreshMetrics()` immediately, so card health/state transitions (e.g., going offline for a snapshot, coming back online after restore) show up right away instead of waiting for the next poll.
- Snapshot buttons track pending countdowns and job locks more cleanly, automatically releasing toggle locks and refreshing job copy as soon as `/api/snapshots` reports the new state.

## Installers & Versioning
- `app.py`, templates, and installer scripts default to `v1.5.6` so the version badge, `/opt` installs, and remote bootstrap helper all pull the same tag.
- README now instructs operators to curl the installer from the release tag to avoid GitHub cache issues that previously served stale scripts.

## Upgrade Notes
- Pull the tag: `git fetch --tags && git checkout v1.5.6`.
- Re-run `install_node_manager.sh` (or `curl -fsSL https://raw.githubusercontent.com/murat-taskaynatan/Blockdag-Node-Manager/v1.5.6/install_nm_from_github.sh | sudo bash`) to sync `/opt`.
- Restart the service: `sudo systemctl restart blockdag-node-manager`.
